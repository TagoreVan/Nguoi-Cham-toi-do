# Nắng trên tháp

A responsive, culture-aware travel guide to Katê and Cham heritage in Ninh Thuận, Vietnam.

## Project overview

This static portfolio project helps young travellers explore Katê, find festival locations, and make a simple two-day itinerary.

## Features

- Katê 2026 activity dates and locations with a link to the referenced Katê Festival page.
- Map search links for the listed locations.
- A two-day itinerary builder with add/remove controls, local browser storage, route links, and shareable URLs.
- Responsive navigation, semantic landmarks, keyboard focus states, and reduced-motion support.

## Built with

HTML, CSS, and vanilla JavaScript. No framework, backend, account, or build step is required.

## Run locally

Open `index.html` in a browser. The itinerary is saved in that browser's local storage; shared itinerary links encode the selected stop IDs in the URL.

## Content and media sources

- Festival schedule: [Katê Festival on Facebook](https://www.facebook.com/KateFestival). Dates and locations can change; check the latest organizer post before travelling.
- Destination photography is loaded from Vietnam.vn and 1cdn.vn. Reuse permission has been confirmed by the project owner.

## Language

The visitor-facing experience is in Vietnamese. This README is in English for portfolio review.
